4. YOUR CODE FILES & WHAT THEY DO (IN PLAIN ENGLISH)
--------------------------------------------------------------------------------
- IplAuctionApplication.java: 
  The starting point of the Spring Boot app. Contains the main() method.

- controller/TeamController.java: 
  Provides URLs (/api/v1/teams) to Create, Read, Update, and Delete teams.

- service/TeamService.java: 
  Business logic for teams. Checks starting budget of Rs 100 Crore.

- controller/PlayerController.java: 
  Provides URLs (/api/v1/players) to list players, add players, or sell them.

- service/PlayerService.java: 
  Checks IPL squad rules: max 25 total players, max 8 overseas players, 
  and deducts the winning bid from the team purse when a player is sold.

- controller/GlobalExceptionHandler.java: 
  Catches errors (like invalid input or empty purse) and returns clean JSON 
  error messages instead of crashing the server with a 500 error.

- dto/SellPlayerRequest.java: 
  Small data container transferring playerId, teamId, and soldAmount.

8. TOP QUESTIONS THE MENTOR CAN ASK YOU & HOW TO ANSWER
--------------------------------------------------------------------------------
Q1: How do you enforce the 25-player and 8-overseas limits?
Ans: In PlayerService, before saving a player as SOLD, I use JPA repository 
     methods countByTeamId(teamId) and countByTeamIdAndOverseasTrue(teamId). 
     If either limit is breached, an exception is thrown.

Q2: Why do you need GlobalExceptionHandler?
Ans: Without it, Spring Boot returns ugly 500 error stack traces. With 
     @ControllerAdvice, we catch exceptions and return neat JSON containing 
     timestamp, HTTP status, and user-friendly error messages.

Q3: What happens to the team budget when a player is sold?
Ans: When sellPlayer() is called, we fetch the team, subtract the sold price 
     from team.getBudget(), and save the updated balance back to the database.
