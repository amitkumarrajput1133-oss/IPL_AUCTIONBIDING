8. TOP QUESTIONS THE MENTOR CAN ASK YOU & HOW TO ANSWER
--------------------------------------------------------------------------------
Q1: Where do you store the JWT token in the frontend?
Ans: When the user logs in via Login.jsx, the server returns a token which 
     we store in localStorage.setItem('token', jwt). For subsequent requests, 
     Axios attaches headers: { Authorization: 'Bearer ' + token }.

Q2: How does the UI update when someone places a bid?
Ans: When a user clicks a bid button in BiddingConsole.jsx, Axios posts to 
     /api/v1/bids/place. When the backend responds with the new bid, App.jsx 
     updates the currentPlayer state, highlights the leading franchise in 
     OrbitArena, and deducts the amount from the Leaderboard.

Q3: Why didn't you use Bootstrap or TailwindCSS?
Ans: We used Vanilla CSS with CSS custom variables to maintain 100% fine-grained 
     control over our cybernetic cricket stadium aesthetic, custom glowing 
     animations, and radial circular positioning without bloated third-party 
     CSS overhead.
