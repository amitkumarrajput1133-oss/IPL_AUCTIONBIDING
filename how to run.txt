# How to Run the IPL Auction System

### 1. Run the Backend (Spring Boot 3)
Open a terminal in the root directory:
```bash
cd backend
..\mvnw.cmd spring-boot:run
```
* Server URL: http://localhost:8082
* In-Memory H2 Console: http://localhost:8082/h2-console (JDBC URL: `jdbc:h2:mem:ipl_auction_db`, User: `sa`, Password: empty)
* Swagger UI API Docs: http://localhost:8082/swagger-ui/index.html

### 2. Run the Frontend (Vite + React)
Open a second terminal in the root directory:
```bash
cd frontend
npm install
npm run dev
```
* Client URL: http://localhost:5173
